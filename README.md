# VitalMedX – نظام متابعة الفريق

لوحة تحكم وبوت تليجرام لمتابعة الدكاترة ومسؤولي الدفعات والمشرفين وخدمة العملاء: المحاضرات، والمهل، والأسئلة، والمشاكل، والتقييمات، والحسابات، والتقارير اليومية.

## التقنية في سطرين

- **Node.js 22، بدون أي مكتبات خارجية** (`npm install` مش مطلوب). قاعدة البيانات SQLite المدمجة في Node (`node:sqlite`)، وبتتحفظ في Docker volume.
- **البوت** شغال بـ Webhook على نفس السيرفر. الفيديوهات وملفات الـ PDF بتفضل على تليجرام، والنظام بيحفظ `file_id` بس.

```
src/server.js   الـ API والصلاحيات وWebhook البوت
src/bot.js      كل رسايل البوت وتسليم الفيديو والأسئلة
src/logic.js    الحالات، والتقييمات، والحسابات، والتقرير، وبرومبت التحليل
src/jobs.js     التذكيرات، والتقرير اليومي، والباك أب (كل دقيقة)
src/db.js       الجداول
public/         لوحة التحكم (HTML/JS/CSS)
scripts/seed.js الجامعات والدفعات والفريق الحقيقي
test/e2e.js     تجربة كاملة بسيرفر تليجرام وهمي (npm test)
```

## التركيب على السيرفر (Contabo · Ubuntu 24.04 · Docker · Nginx)

### 1. حضّر تليجرام
1. من **@BotFather**: اعمل `/newbot` باسم `VitalMedXBot` وخد الـ **Token**.
2. اعمل **قناة خاصة** للباك أب، وضيف البوت فيها **أدمن**. هات الـ Chat ID بتاعها (بيبدأ بـ `-100`)، مثلاً من @RawDataBot بإنك تعمل Forward لرسالة من القناة.
3. هات الـ Chat ID بتاع الأدمن من **@userinfobot**.

### 2. الدومين
اعمل سجل **A** لـ `team.vitalmedx.app` يشاور على IP السيرفر.

### 3. شغّل النظام
```bash
cd /opt && git clone <repo> vitalmedx   # أو فك الملف المضغوط هنا
cd vitalmedx
cp .env.example .env && nano .env       # املا كل القيم
docker compose up -d --build
docker compose exec app npm run seed    # بيطبع إيميلات وكلمات مرور الفريق: احفظها
```

### 4. Nginx و HTTPS
```bash
cp deploy/nginx-team.vitalmedx.app.conf /etc/nginx/sites-available/team.vitalmedx.app
ln -s /etc/nginx/sites-available/team.vitalmedx.app /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
certbot --nginx -d team.vitalmedx.app
```

### 5. اربط البوت
```bash
docker compose exec app npm run set-webhook
```
لازم كل سطر يرجع فيه `"ok":true`، وفي آخر سطر تلاقي عنوان الـ Webhook صح.

### 6. جرّب
افتح `https://team.vitalmedx.app` وادخل بحساب الأدمن. من **الإعدادات ← المستخدمين** ضيف الدكاترة بأسعارهم وطاقتهم. كل واحد بياخد كود `VM-XXXXX` يبعته للبوت عشان حسابه يتربط.

## التشغيل اليومي

| المهمة | الأمر |
| --- | --- |
| اللوجات | `docker compose logs -f --tail 200` |
| تحديث بعد تعديل الكود | `git pull && docker compose up -d --build` |
| باك أب يدوي | من اللوحة: الإعدادات ← إعدادات عامة ← "اعمل باك أب دلوقتي" |
| الرجوع لنسخة احتياطية | `docker compose down`، انسخ الملف على `vitalmedx.db` جوه الـ volume (`docker volume inspect vitalmedx_vmx-data`)، وبعدين `docker compose up -d` |

الباك أب بيتعمل تلقائي كل يوم في الميعاد اللي في الإعدادات، وبيتبعت للقناة الخاصة، وآخر 7 نسخ بيفضلوا على السيرفر كمان.

## القواعد اللي النظام ماشي عليها

- **الدكتور** معاه 24 ساعة للفيديو و24 ساعة منفصلين لملف الأسئلة. مابيشوفش أي اسم جامعة أو دفعة أو كود، بيشوف اسم المحاضرة ونوعها وسعرها بس.
- **المعادة** بنص سعر النظري تلقائي، والمسؤول يقدر يغيّر أي سعر. كل تعديل بيتسجل بالاسم، والدكتور بيتبلّغ.
- **مسؤول الدفعة** معاه نص ساعة يرفع المحاضرة بعد الاعتماد، وساعة يرجّع رد الدكتور لخدمة العملاء.
- **خدمة العملاء** معاها نص ساعة توصّل الرد للطالب.
- **الحسابات:** الدكتور بيتحاسب على اللي سلّمه بس، واللي ماتسلمش بيترحّل للفترة الجاية. فيه تقفيل شهري وتقفيل معجّل.
- **التقييمات:**
  - الدكتور: الموعد 35، الفيديو 40، الأسئلة 10، التعليمات 10، التواصل 5.
  - مسؤول الدفعة: الاشتراكات مقابل المتوقع 30، المهل 30، المشاكل 20، الليستة 20.
  - المشرف: الاشتراكات 40، التقصير والتأخير 30، المشاكل 20، التقرير 10.
- كل المهل والنسب بتتغير من **الإعدادات ← إعدادات عامة**.

## الأمان
- كلمات المرور متخزنة بـ scrypt، والجلسة كوكي موقّعة `HttpOnly` و `Secure`.
- كل طلب تعديل لازم يكون من اللوحة نفسها (حماية CSRF).
- الـ Webhook بيتأكد من `secret_token` بتاع تليجرام.
- السيرفر الداخلي مفتوح على `127.0.0.1:3100` بس، والوصول من برة عن طريق Nginx.
